# Zedu Dash

A dependency-free arcade runner for start.ng. Open `index.html` to play: arrow keys or A/D to move, P or Escape to pause, touch buttons or swipe on mobile. Collect gold for 25 points and avoid the coral blocks. Survival earns 10 points per second and difficulty gradually increases. Personal bests stay on the current device.

The start.ng connect bridge loads the signed-in character (or the platform guest), displays their profile, and applies their body, outfit colours, skin, hair, hat and accessories to the runner. Offline/local play uses a fallback character. Character integration requires hosting on start.ng.

No install or build step. Publish the `feat/zedu-dash` branch through start.ng. All gameplay assets are local; the only service is the official start.ng character bridge.

AI usage: Codex assisted with implementation and cover artwork.
